ARCHITECTURE:
================================================================================
React + TypeScript (Vite)  ->  Node.js + Express API  ->  MySQL 8
- All data is stored in MySQL; the browser never talks to the database.
- Plain SQL through mysql2 with ? placeholders (no ORM).
- Passwords hashed with bcrypt; login with a JWT signed by JWT_SECRET.
- No email/SMS services, no payment gateway, no Supabase/Firebase.

================================================================================
DATABASE: 8 TABLES, 12 FOREIGN KEYS
================================================================================
1. users           (id PK, name, email UNIQUE, password_hash, role, college, reg_no, created_at)
2. events          (id PK, organizer_id FK->users, title, description, category, venue,
                    event_date, registration_deadline, capacity, fee, team_min, team_max, created_at)
3. teams           (id PK, event_id FK->events, name, join_code UNIQUE, leader_id FK->users, created_at)
4. team_members    (team_id FK->teams, user_id FK->users, joined_at; PRIMARY KEY(team_id, user_id))
5. registrations   (id PK, user_id FK->users, event_id FK->events, team_id FK->teams NULL,
                    status 'confirmed'/'cancelled', checked_in_at, registered_at;
                    UNIQUE(user_id, event_id))
6. announcements   (id PK, event_id FK->events, title, content, created_at)
7. event_questions (id PK, event_id FK->events, user_id FK->users, question, answer NULL, created_at)
8. event_winners   (id PK, event_id FK->events, position, winner_name, prize NULL)

DBMS concepts shown: primary keys (incl. composite), foreign keys with CASCADE /
SET NULL, one-to-many and many-to-many relationships, CRUD, INNER and LEFT JOIN,
COUNT / GROUP BY / HAVING, UNIQUE / NOT NULL / CHECK constraints, and
transactions with SELECT ... FOR UPDATE row locks.

================================================================================
FEATURES:
================================================================================
1.  Event directory with search, category / college / price / solo-team /
    date filters, sorting and local bookmarks.
2.  Event detail page with venue map & distance, seats left, deadline,
    calendar export (Google Calendar / .ics).
3.  Solo registration with server-side deadline, capacity and duplicate checks.
4.  Team registration: create a team, get a 6-character join code, teammates
    sign up and join with the code.
5.  QR tickets (SHOWUP-REG-<id>) and downloadable PNG passes.
6.  Organizer QR check-in (camera or typed ticket number).
7.  Announcements, Q&A (organizer answers) and Winners tabs.
8.  Organizer studio: create / edit / delete events, participants by team,
    CSV export.
9.  Profile page with registration and attendance summary.
10. Participation certificate image - DEMO feature, not an official or
    verifiable certificate.
The event fee is informational only; there is no payment processing.
