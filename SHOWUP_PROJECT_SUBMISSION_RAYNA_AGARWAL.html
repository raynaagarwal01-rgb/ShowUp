1. Executive Summary & Project Mission

At large university campuses such as VIT Vellore, thousands of students engage in hackathons, technical masterclasses, esports tournaments, and cultural competitions across major festivals like graVITas and Riviera. However, the existing registration and discovery process is fragmented across scattered WhatsApp links, Google Forms, and manual check-in sheets.

The Solution — ShowUp: An end-to-end modern web application providing instant event discovery, team formation with secret join codes, online UPI and card payment processing, automated high-contrast offline passes (PNG photo pass), client-side 1920x1080 participation certificate generation, real-time organizer announcement broadcasts, per-event Q&A discussion forums, calendar synchronization (Google & iCal), and comprehensive On-Duty (OD) attendance export for university administration.

2. Complete Page-by-Page & Button-by-Button Guide

Page 1: Landing Page (/)

The gateway welcoming students and organizers to the campus event ecosystem.

"Explore Events" Button Directs users to the live directory (/events) with full search and filters.
"Host an Event" Button Navigates club leads to the Organizer Studio (/organizer) to publish events.
"Sign In / Get Started" Buttons Launches student & organizer authentication flows with immediate session persistence.
Category Pill Tiles Instant shortcuts filtering Hackathons, Workshops, Cultural, and Competitions.

Page 2: Events Directory Page (/events)

The centralized search and discovery engine featuring multi-dimensional filtering.

Live Keyword Search Input Real-time instant filtering matching event title, tagline, club name, venue, or college.
Scope Segmented Control ("All" / "Internal" / "External") Filters events restricted to campus students versus open to outstation colleges.
Category Badges Row One-click pills: "All", "Hackathon", "Workshop", "Competition", "Cultural", "Talk".
"Saved (count)" Wishlist Pill Filters the view to only bookmarked events shortlisted by the student.
From-Date & To-Date Calendar Range Pickers Narrows down events scheduled between specific dates.
Sort Dropdown Menu Sorts by "Soonest First", "Latest First", "Fee: Free First", "Fee: Low to High", etc.
Event Card Bookmark Button (Heart/Ribbon) Toggles immediate saving of the event to local storage without page reload.

Page 3: Event Details & Registration Page (/events/:id)

Comprehensive event portal with interactive participation tabs and registration actions.

Tab: "Overview & Rules" Displays complete formatted description, eligibility, and numbered contest rules.
Tab: "Announcements" Displays real-time organizer broadcast feed with glowing URGENT ALERT badges.
Tab: "Q&A Forum" Student discussion thread with "Ask a Question" box and verified organizer replies.
"Register" / "Create Team" / "Join with Code" Handles solo registration, team creation with unique join code, or joining via code.
"Download Pass (PNG)" Button Generates an 800x1080 high-contrast photo pass with QR code for offline door entry.
"Download / Preview Certificate (PNG)" Button Renders high-res 1920x1080 participation certificate with ShowUp seal & verification QR.
"Add to Calendar" Dropdown Directly exports to Google Calendar or downloads .ics file for Apple & Outlook.

TypeScript 6 Microsoft Static type safety; eliminates null pointer exceptions and guarantees data schema integrity. All models (EventRecord, Registration, Announcement, EventQuestion) are strictly typed.

4. Key Architectural & Functional Innovations

  • Dual-Mode Resilience (Cloud & Offline Demo Db): If internet connection drops or API keys are missing, the system gracefully degrades to the local Indexed/LocalStorage demo database without crashing.
  • Instant Client-Side Certificate Synthesis: Eliminates costly PDF rendering servers by generating 1080p certificates on HTML5 Canvas in under 80 milliseconds.
  • Official Academic OD Attendance CSV: Standardized to VIT Vellore administrative guidelines for automated submission to Student Welfare Offices.
  • Comprehensive UPI Payment Gateway Simulation: Realistic checkout modal supporting GPay, PhonePe, Paytm, and QR Scan with zero processing fees.
